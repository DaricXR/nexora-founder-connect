README · How Nexora Works

Your quick-start guide to the workspace, tools, data, and outreach process.

1 · Discover

Choose country, industry, and role in Founder Discovery. The protected Supabase Edge Function searches public sources with Tavily. Each result is a research candidate: verify the person before saving.

2 · Qualify

Add useful decision-makers to Lead CRM. Score company fit and potential. Keep separate pipelines for client projects, partnerships, and international career opportunities.

3 · Contact

Use Outreach Studio for editable LinkedIn or email drafts. Send messages yourself. Check Contacted to move leads into Already Contacted; set follow-up dates and record replies.

4 · Find jobs

In Job Openings, search public listings, verify the job on the employer's own site, save roles, and track application stages from Saved to Interview or Offer.

5 · Monitor

GitHub Actions runs the scheduled Python monitor. It checks configured Greenhouse/Lever boards and optional Tavily public-web research. Findings are stored under your Supabase account.

6 · Review

Alerts & Daily Priorities retrieves stored findings with Refresh. Mark them Reviewed or Dismissed. Insights summarizes CRM stages and replies, while Usage & Limits tracks quotas.

Data, security & limitations

When signed in, your leads, companies, jobs and alerts are stored in Supabase. Refresh reloads saved records; Load More paginates saved records. Searching the public web is a separate action, and results may be outdated. Only you can approve messages and applications.

GitHub Pages hosts no private keys or database server. Sensitive API keys remain in Supabase secrets or GitHub Actions secrets. The monitor is configured for a single account through NEXORA_USER_ID. Cloud sync, live usage and discovery need their respective services deployed.

For complete setup and operations, read Project README ↗, Usage setup ↗, and GitHub monitoring logs ↗.

How the system works

GitHub Pages hosts the interface. Workspace tabs include Founder Discovery, Lead CRM, Job Openings, and Settings. Live job discovery requires deploying the separate discover-jobs Edge Function. GitHub Pages itself cannot run scheduled checks. Supabase Auth and Postgres securely store each signed-in user’s records. Refresh re-queries the database; Load More requests the next database page. Discovery uses a server-side Tavily integration when configured. Browser-local demo mode is available without setup and does not synchronize. Export JSON backups regularly.
