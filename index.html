How the system works

GitHub Pages hosts the interface. Workspace tabs include Founder Discovery, Lead CRM, Job Openings, and Settings. Live job discovery requires deploying the separate discover-jobs Edge Function. GitHub Pages itself cannot run scheduled checks. Supabase Auth and Postgres securely store each signed-in user’s records. Refresh re-queries the database; Load More requests the next database page. Discovery uses a server-side Tavily integration when configured. Browser-local demo mode is available without setup and does not synchronize. Export JSON backups regularly.
